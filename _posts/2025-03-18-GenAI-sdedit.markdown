## Ⅰ. INTRO

SDEdit는 **사용자가 지정한 일반적인 가이드를 바탕으로**, **세부적인 이미지를 생성 및 편집**하는 모델이다. 해당 모델은 생성 과정 자체를 **"하이재킹(hijack)"**하여, 현실성(reality)과 신뢰성(faithfulness)을 동시에 추구한다.

### Key Points
- **Goal**: 가이드를 기반으로 세부 이미지 생성
- **Main Concepts**: 현실성, 신뢰성, 생성 과정 하이재킹
- **Applications**:
  - Stroke 기반(가이드) 이미지 생성
  - Stroke 기반(가이드드) 이미지 편집
  - 이미지 합성

### 기존 접근 방식의 한계
- **Conditional GANs**: 데이터 수집과 모델 재학습이 필요하다
- **GAN Inversion**: 작업마다 별도 손실 함수 필요하다다 -> 범용성 부족



## Ⅱ. BACKGROUND

### Image Synthesis with SDE
SDE를 기반으로 하는 이미지 생성은 다음의 개념을 바탕으로 한다:

- $$P_0 = P_{data}$$ (초기 상태: 실제 데이터 분포)
- $$P_1$$ (최종 상태: 노이즈 분포)
- $$P_0$$ 에서 시작하여 이미지를 점진적으로 노이즈로 바꾸고, 이를 $$P_1$$ 되돌리는 과정을 통해 이미지를 생성한다.

### 주요 SDE 종류
- **VP-SDE (Variance Preserving)** : 노이즈의 분산이 천천히 증가하고 전체 분산이 일정하게 유지한다.
- **VE-SDE (Variance Exploding)** : 기존 데이터에 급격하게 증가하는 노이즈를 덮어 노이즈화 시킨다.


### 수치적 해법
- **Denoising Score Matching**을 통해 SDE의 score function 학습한다.
- 이후 **Euler-Maruyama 방법**으로 수치적으로 해석한다.
- **SDE 구성**:
  - **Drift Term** : 데이터가 어떤 방향으로 가는지 결정. 즉, 순방향 프로세스에서는 데이터 분포에서 멀어지는 쪽으로 이동한다.
  - **Diffusion Term** : 무작위성을 부여하여 데이터를 노이즈화한다.



## Ⅲ. SDEdit

SDEdit는 기존의 score-based generative 모델을 변형하여, 특정 시간 $$t_0$$ 에서 노이즈가 추가된 이미지를 초기 상태로 삼아 생성 과정을 조절한다. 이는 사용자가 제공한 가이드 이미지를 출발점으로 하여 **보다 현실적이며 신뢰도 높은 결과를 생성**할 수 있게 해준다.

### 생성 과정 하이재킹
- 기존의 score-based 모델은 $$x(1)$$ (노이즈 상태)부터 $$x(0)$$ (데이터)로 복원한다.
  SDEdit는 이 과정을 $$x(t_0)$$에서 시작하여, 주어진 가이드 이미지에서 노이즈를 추가하고, 이를 복원하여 **제한된 조건 내에서의 생성**을 수행한다.
- $$x(t_0)$$ 에서 과정을 시작하는 이유는 사용자의 가이드가 일부 보존되어야하기 때문이다.

### 장점
- 역문제 해결을 위한 복잡한 기술 불필요하다.
- paired dataset 없이도 효과적인 편집 가능하다.
- 다양한 입력 품질에 대응 가능하며, 저품질 입력은 높은 $$t_0$$ 값을 사용하여 노이즈를 더 추가한 상태에서 복원한다.

### Guide의 품질과 $$t_0$$
- 입력 이미지의 품질이 낮을수록 더 높은 $$t_0$$를 설정하여 더 많은 노이즈를 추가하고, 복원을 통해 제약을 덜 받게 생성 가능하다.
- 품질이 높은 경우, 낮은 $$t_0$$를 선택하여 가이드의 정보를 보다 정확히 반영할 수 있다.
  (*'생성 과정 하이재킹'* 부분에서 설명한 가이드를 보존하는 정도를 사용자가 정할 수 있다는 것이다.)
- 현실성과 신뢰성은 trade-off 관계이므로 적절한 $$t_0$$ 선택이 중요하다.



## Ⅳ. EXPERIMENT

### 1. Stroke-Based Image Synthesis
- 단순한 선 드로잉을 입력으로 하여 사실적인 이미지를 생성한다.
- 선의 위치나 형태만으로도 충분히 높은 수준의 세부 묘사가 가능하다.

### 2. Flexible Image Editing
- 기존 이미지를 stroke 기반으로 수정한다.
  (예: 사물의 형태 수정, 위치 변경, 일부 영역만 대체 등)
