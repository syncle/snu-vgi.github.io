# InstructPix2Pix: 이미지 편집을 위한 Diffusion 모델

InstructPix2Pix는 기존의 text-to-image 생성 모델을 확장하여, 인간의 지시와 원본 이미지를 입력받아 수정된 이미지를 출력하는 강력한 편집 모델입니다. Stable Diffusion과 GPT-3 등의 사전 학습 모델을 효과적으로 결합하여 대규모 학습 데이터를 자동으로 생성하고, 이를 바탕으로 세밀한 편집 능력을 학습시킵니다.

아래에서는 InstructPix2Pix의 핵심 아이디어, 학습 과정 및 데이터를 생성하는 방법, 실험 결과와 한계점에 대해 수식과 함께 상세하게 살펴보고, 추가로 구체적인 시나리오와 프레임워크 구성 방식도 설명합니다.

---

## 1. Introduction

### 1.1 목표와 배경
- 기존의 text-to-image 모델은 텍스트 프롬프트만 입력받아 이미지를 생성하지만, 실제 응용에서는 원본 이미지의 일부만 수정하고자 하는 경우가 많습니다.
- 이전 방식은 이미지의 특정 부분을 가리거나 복잡한 도구를 통해 영역을 지정해야 했던 반면, InstructPix2Pix는 사람이 작성한 간단한 문장으로 직접 편집 지시를 내릴 수 있도록 설계되었습니다.
- 본 기법은 사람이 입력한 지시와 원본 이미지 정보를 결합하여, 전체 이미지 구조는 유지하면서 원하는 부분만 수정할 수 있는 효과적인 편집을 목표로 합니다.

### 1.2 InstructPix2Pix의 특징
- 인간의 지시를 바로 반영한 이미지 편집
  - 예: “배경을 밝게 해주세요”, “머그컵을 와인잔으로 바꿔주세요”
- Stable Diffusion의 파인튜닝을 통해 모델을 처음부터 학습하지 않고도 효과적인 편집 성능을 달성
- GPT-3와 Prompt2Prompt 기법을 활용해 (원본 이미지, 편집된 이미지, 편집 지시) 형태의 대규모 합성 데이터를 자동으로 생성

## 2. Method: InstructPix2Pix

InstructPix2Pix는 두 가지 주요 단계로 구성됩니다. 첫 번째는 트레이닝 데이터를 생성하는 단계이며, 두 번째는 생성된 데이터를 바탕으로 모델을 학습시키는 단계입니다.

### 2.1 Data Generation

#### 2.1.1 캡션 및 지시 생성
1. **초기 캡션 수집**  
   - LAION 등의 데이터셋에서 캡션을 수집합니다.
   - 수집된 캡션 중 일부(약 700개 정도)는 사람이 직접 편집 지시와 편집된 캡션을 레이블링하여 소규모 트리플렛(triplet) 데이터를 구성합니다.

2. **GPT-3 파인튜닝**  
   - 사람이 레이블링한 700개의 트리플렛 데이터를 이용해 GPT-3를 단기간 파인튜닝합니다.
   - 파인튜닝된 GPT-3는 주어진 캡션에 대해 다양한 편집 지시와 편집된 캡션을 자동으로 생성할 수 있게 됩니다.
   - 이후 LAION 데이터셋의 수많은 캡션(약 45만 건)에 대해 편집 지시와 편집 캡션을 생성하여 대규모 caption-instruction triplet을 구축합니다.

#### 2.1.2 이미지 쌍 생성: Prompt2Prompt 활용
- **기본 원리**  
  - 입력 캡션(원본 캡션)과 GPT-3가 생성한 편집 캡션에 대응하는 이미지를 생성합니다.
  - 가장 직관적인 방법은 supervised 학습을 위한 입력-출력 쌍, 즉 트리플렛을 구성하는 것입니다.
- **Prompt2Prompt 기법**  
  - Stable Diffusion을 이용해 원본 캡션에 해당하는 이미지를 먼저 생성합니다.
  - 이어서 편집 캡션에 대해 동일한 구조를 유지하도록, 초기 생성 이미지와 그 때의 크로스 어텐션 맵을 활용하여 이미지를 생성합니다.
  - 크로스 어텐션은 각 픽셀의 쿼리와 텍스트 토큰의 키를 연결하여 여러 어텐션 맵을 생성하는데, 예를 들어 5개 토큰이 있다면 5개의 어텐션 맵이 생성됩니다.
  - inference 시, 실제 토큰들의 값과 곱해 최종 피처맵을 산출하게 되며, 필요에 따라 어텐션 맵 전체를 교체하거나 일부 토큰의 맵만 추가 또는 스케일링하는 식으로 세밀한 조절이 가능합니다.
- **데이터 필터링**  
  - 생성된 후보 이미지 중, 100개 정도의 이미지를 생성한 후 서로 간의 유사도 및 캡션 간 유사도, 그리고 Directional CLIP similarity 기준(예, 이미지 유사도 0.75 이상, 캡션 유사도 0.2 이상, Directional CLIP similarity 0.2 이상)을 만족하는 경우 최대 4개만 선택하여 최종 트리플렛 데이터셋을 구성합니다.
  - Directional CLIP similarity는 텍스트 임베딩의 변화와 이미지 임베딩의 변화를 비교하여, 텍스트가 바뀔 때 이미지가 바뀌는 방향이 일치하는지 평가하는 방식으로, 기존 Style-NADA 기법에서 제안되었습니다.

## 3. Model Architecture & Fine-tuning

### 3.1 Stable Diffusion 기반 모델
- Stable Diffusion은 픽셀 공간 대신 잠재 공간에서 확률적 forward(순방향) 및 reverse(역방향) 과정을 수행하는 latent diffusion 모델입니다.
- forward 과정에서는  
  $$
  q(z_t \mid z_{t-1}) = \mathcal{N}\Bigl(z_t; \sqrt{\alpha_t}\,z_{t-1},\ (1-\alpha_t)I\Bigr)
  $$
  와 같이 노이즈를 점진적으로 추가합니다.
- reverse 과정에서는 네트워크가 현재 단계의 노이즈를 예측하여 denoising을 수행합니다.

### 3.2 추가 입력 조건: 원본 이미지와 편집 지시
- 기존 모델은 텍스트만 조건으로 받았으나, InstructPix2Pix에서는 원본 이미지와 편집 지시 텍스트 두 가지 조건을 동시에 고려합니다.
- 원본 이미지의 잠재 표현을 입력 조건으로 사용하고, 편집 지시 텍스트는 그대로 반영하여 모델이 두 조건을 모두 활용하도록 파인튜닝합니다.

### 3.3 Classifier-free Guidance 확장
- 조건이 두 가지로 늘어남에 따라, 기존의 classifier-free guidance 기법을 확장하여 각각의 조건(원본 이미지, 텍스트, 편집 지시)에 대해 별도의 guidance term을 적용합니다.
- 학습 시 일정 비율로 조건을 비워 모델이 다양한 조건 하에서도 일반화할 수 있도록 합니다.
- inference 단계에서는 두 조건을 혼합하여 원하는 편집 강도를 조절합니다.
  $$
  \hat{\epsilon}_\theta = w \cdot \epsilon_\theta(z_t, \text{조건}) + (1-w)\cdot \epsilon_\theta(z_t)
  $$
  에서 $$w$$는 가이던스 스케일로 조정됩니다.

### 3.4 Training Objective
- 학습은 전형적인 DDPM 손실 함수를 사용하며, 다음과 같이 표현됩니다.
  $$
  \mathcal{L}(\theta) = \mathbb{E}_{z_0,\,\epsilon,\,t}\Bigl[\|\epsilon - \epsilon_\theta(z_t, c)\|^2\Bigr]
  $$
  여기서 $$c$$는 (원본 이미지 + 편집 지시) 조건을 의미합니다.

## 4. Experiments

InstructPix2Pix를 이용한 이미지 편집 실험은 여러 시나리오에서 진행되었습니다.

### 4.1 단일 이미지 편집
- 예: “새를 용으로 바꿔주세요”, “의자 색상을 파란색으로 변경해 주세요”
- 원본 이미지의 구도를 유지하면서 특정 부분만 자연스럽게 변경

### 4.2 연쇄 편집
- 여러 단계의 편집 지시를 순차적으로 적용하여, 예를 들어 배경을 밤하늘로 바꾸고 인물을 로봇으로 변경한 뒤 만화풍으로 전체를 수정하는 실험을 진행
- 각 단계별로 점진적인 변화가 이루어져 최종적으로 일관된 편집 결과 도출

### 4.3 잠재 노이즈 변화
- 샘플링 시 삽입되는 노이즈를 달리하여 동일한 편집 지시에도 다양한 결과물을 생성
- 사용자가 노이즈 고정 기능을 선택하면 일관된 결과, 랜덤 노이즈 사용 시 다양한 편집 결과 제공

### 4.4 실패 사례 및 한계
- 복잡한 지시(배경, 스타일, 인물 동작 등 여러 요소 동시 수정)의 경우 모델이 부정확한 결과를 낼 수 있음
- 대규모 사전 학습 모델의 편향이 결과에 영향을 미칠 수 있음

### 4.5 성 편향 및 데이터 축소에 따른 성능 저하
- 특정 지시(예: “화난 의사 이미지 생성”)의 경우 특정 성별 이미지가 과도하게 생성되는 문제가 발생할 수 있음
- 소규모 데이터셋으로 학습 시 편집 범위가 제한되며, CLIP Filtering을 제거하면 생성 이미지의 품질이 낮아짐

## 5. 추가 상세 설명: 트레이닝 데이터 생성과 모델 학습 과정

이번 절에서는 InstructPix2Pix의 구체적인 시나리오와 프레임워크를 두 단계로 나누어 상세히 설명합니다.

### 5.1 트레이닝 데이터 생성 단계
- **목표**  
  인간의 지시와 원본 이미지로부터 수정된 이미지를 출력하는 모델 학습을 위해, supervised 러닝에 적합한 입력-출력 트리플렛을 구성합니다.
  
- **데이터 수집 및 최소 데이터 구성**  
  - 우선 LAION 데이터셋에서 캡션만을 랜덤하게 700개 정도 샘플링합니다.
  - 나머지(편집 지시와 편집 캡션)는 사람이 직접 레이블링하여 소규모 셋을 구성합니다.
  
- **GPT-3 파인튜닝을 통한 데이터 확장**  
  - 위의 700개 데이터를 기반으로 GPT-3를 한 번의 epoch 동안 파인튜닝합니다.
  - 파인튜닝된 GPT-3는 주어진 input 캡션에 대해 다양한 edit instruction과 edit caption을 생성합니다.
  - 이를 통해 약 45만 건의 편집 지시 및 편집 캡션을 생성하고, 각각에 대응하는 이미지를 생성하는 기반 데이터를 마련합니다.
  
- **Prompt2Prompt를 통한 이미지 생성**  
  - 입력 캡션을 바탕으로 Stable Diffusion을 사용해 원본 이미지를 생성합니다.
  - 편집 캡션이 주어지면, 처음 생성된 캡션과 이미지, 그리고 해당 시점의 크로스 어텐션 맵을 활용하여 원하는 부분만 수정하는 이미지를 생성합니다.
  - 크로스 어텐션은 각 픽셀의 쿼리와 텍스트 토큰의 키를 이용해 여러 어텐션 맵을 산출하는데, 특정 토큰에 해당하는 어텐션 맵만 변경하거나, 추가 단어에 대한 어텐션 맵을 삽입 및 스케일링하는 방식으로 원하는 편집 효과를 조절할 수 있습니다.
  - 후처리 과정에서는 후보 이미지 100개를 생성한 후, 이미지 유사도와 캡션 유사도, Directional CLIP similarity 기준을 적용해 최대 4개의 데이터만 최종적으로 선택합니다.

### 5.2 모델 학습 단계
- **기존 모델의 활용 및 파인튜닝**  
  - 새로운 모델을 처음부터 설계하는 대신, latent diffusion 모델(Stable Diffusion)의 대부분의 weight를 그대로 활용합니다.
  - 다만, 에디팅을 위해 원본 이미지 정보를 입력 조건으로 제공해야 하므로, 기존 3채널 이미지 입력에 추가 채널(원본 이미지 정보)을 연결하여 모델을 확장합니다.
  - 이 과정에서 추가되는 weight는 초기값을 0으로 설정한 후, 10,000 스텝 정도 파인튜닝합니다.
  
- **Classifier-free Guidance의 확장 적용**  
  - 원본 이미지, 텍스트, 편집 지시 각각에 대해 별도의 guidance term을 부여하여, inference 시에 세밀하게 편집 강도를 조절합니다.
  - 이를 통해 모델은 입력 이미지의 구조를 유지하면서도, 편집 지시를 효과적으로 반영한 결과물을 생성할 수 있습니다.
  
- **학습 및 Inference 성능**  
  - A100 8개 GPU를 활용해 약 하루 정도의 파인튜닝을 진행하였으며, inference 시 평균 9초 내외의 속도로 편집 결과를 산출할 수 있음을 확인하였습니다.
  - 중간중간 CLIP 기반 평가를 통해 데이터 퀄리티를 관리하며, 전체 모델의 안정성과 성능을 확보하였습니다.

## 6. Conclusion

InstructPix2Pix는 Stable Diffusion과 GPT-3로부터 생성한 대규모 합성 데이터를 바탕으로, 원본 이미지와 인간의 지시를 입력받아 수정된 이미지를 직접 출력하는 혁신적인 편집 모델입니다.

1. **데이터 자동 생성**  
   - GPT-3를 활용한 캡션 변형과 Prompt2Prompt 기법으로 (원본 이미지, 편집 이미지, 편집 지시) 트리플렛을 대규모로 생성
2. **Stable Diffusion 파인튜닝**  
   - 원본 이미지와 편집 지시를 모두 조건으로 주어 역방향 디퓨전 과정을 통해 자연스러운 편집 결과 도출
3. **세밀한 편집 효과**  
   - 구조 유지와 동시에 특정 부분만 수정하는 다양한 편집 효과 구현
4. **추가 상세 시나리오**  
   - 최소 데이터셋 구성부터 GPT-3 파인튜닝, 크로스 어텐션 조절 및 데이터 필터링까지의 전 과정을 통해 실용적인 트레이닝 데이터 생성 및 모델 학습 전략 마련
5. **한계 및 미래 확장**  
   - 복잡한 지시 처리, 편향 문제, 해상도 및 세밀 제어 등 일부 한계가 존재하지만, 향후 다양한 기법을 접목하여 개선할 여지가 충분함

> **요약**: InstructPix2Pix는 단순 텍스트 기반 이미지 생성에서 나아가, 원본 이미지와 인간 지시를 결합하여 원하는 부분만 효과적으로 수정하는 모델로, 데이터 생성부터 모델 학습에 이르는 전 과정을 체계적으로 구성한 점이 특징입니다.
